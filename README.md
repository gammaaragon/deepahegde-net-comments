# deepahegde-net-comments

Reader comment threads for [deepahegde.net](https://deepahegde.net).

There is no code here. The site's articles carry a comment box at the
bottom, which is [giscus](https://giscus.app) — a small open-source widget
that stores each page's comments as a GitHub Discussion in this repository.
Commenting from the site signs you in with GitHub and posts here.

The site itself is built from a separate, private repository.

## Why a separate repository

giscus needs a public repository, so that anyone reading an article can see
the thread and reply to it. Keeping that repository separate from the site's
source means reader discussions stay out of the site's own history, and it
gives the threads somewhere sensible to live.

## Where the threads are

Under [Discussions](https://github.com/gammaaragon/deepahegde-net-comments/discussions),
in the **Announcements** category — one thread per article, created
automatically the first time someone comments on that page. The category
format means readers reply to an article's thread rather than opening new
ones.

## Reporting a problem with an article

A comment on the article's own thread is the best place. For anything you
would rather not post publicly, the site has a
[contact page](https://deepahegde.net/contact/).
